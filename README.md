# 📊 Superstore Sales Dashboard | Power BI

## 📌 Project Overview

An interactive Power BI dashboard developed to analyze sales performance, profitability, customer segments, and product trends. The dashboard provides actionable business insights through interactive visualizations and DAX calculations.

## 🎯 Objectives

* Analyze sales and profit performance.
* Identify top-performing products and categories.
* Compare current and previous year sales.
* Monitor regional and segment-wise performance.
* Track return rates and business trends.

## 🛠️ Tools & Technologies

* Power BI Desktop
* Power Query
* DAX
* Excel
* Star Schema Data Modeling

## 📂 Data Model

**Fact Table:** Orders

**Dimension Tables:** Date, Returns, People

## 📈 Key DAX Measures

* Total Sales
* Total Profit
* Total Orders
* Profit Margin
* Sales YTD, MTD, QTD
* Previous Year Sales
* Return Rate

## 🚀 Features

✅ KPI Cards
✅ Interactive Slicers
✅ Time Intelligence Analysis
✅ Tooltips & Drill Through
✅ Conditional Formatting
✅ Previous Year Comparison
✅ Dynamic Business Status Classification

## 📊 Visualizations

* KPI Cards
* Line & Bar Charts
* Donut Chart
* Treemap
* Filled Map
* Table Visuals
* Tooltips & Drill Through

## 🔍 Key Insights

* Technology category generated the highest sales.
* Regional sales performance was analyzed.
* Sales trends were compared with previous year performance.
* Business performance was evaluated using dynamic measures.
